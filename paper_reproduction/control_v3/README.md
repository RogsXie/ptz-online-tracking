# 改进控制尝试 v3

首批已在32轮、2635条交互、4760次更新后按异常/预算规则停止。最后训练探针4/8通过，4例持续反向过多；独立验证未启动。诊断与新静态观测修复见 `../verification/improved-control-v3-20261031/STOPPED32_REPORT.md` 和 `../control_v4/README.md`。本目录代码保留历史配置。

用户在作者源码训练失败后授权针对不足改进。此版本明确不再声称严格复现源码；历史源码版、v2、检测器和 ReID 均保留。

首个实验从头学习静态居中，固定 FOV，最多32轮。入口 `scripts/train_improved_control_50mamba.py --output <新目录> --episodes 32 --headless`。

- 消除旧 Q 网络的跨动作时长干扰：每个动作的 Q 仅取决于该动作自己的时长；其他时长槽固定中点，七次前向取对角输出。
- 使用既有 v2 的图像居中奖励和正确的最新动作历史；去除作者置信度连续10步的完成奖金和提前结束。状态、奖励和策略均不读取 GT。
- 时长直接为0.04–0.25物理秒，云台8度/秒；不是作者参数÷5配置。Q学习率0.0005，参数学习率0.0001，batch128，gamma0.98，预热256条，每条真实RGB交互2次更新，target每100次更新同步。epsilon按交互从0.8线性降至0.02（4000步）。这些是显式改动。
- 保持已有独立质量门槛：每例10模拟秒，4秒内稳定并保持至少5秒；末段平均径向误差≤0.025、P95≤0.05，控制反向频率等约束不降低。40例至少38例通过，四象限每组至少9/10。
- 训练种子211000起；冻结训练分区探针219100–219107，每8轮一次；全部8例通过才进入510000–510039的独立验证。探针结果不是独立验证。最终测试分区保持未使用。
- 训练前真实UE检查4例Stay必须全部失败、目标可见、定向脉冲实际响应正确且改善画面的脉冲得到正奖励。这只验证环境基本可学条件，不是证明策略能稳定控制。
- 非有限数值、动作时长/云台响应不一致立即停止；从第16轮检查贪婪策略的原地不动、机械限位、持续丢失、反复反向，以及奖励提高但居中恶化；32轮未过训练探针则停止复查。初始探索失败不直接等同代码异常。
- 保存每轮检查点、完整逐步/更新日志、源代码快照与前端hash。异常保存incident、failure和interrupted检查点，修复后使用新目录；不能删除失败记录或改写已发生的实验。
- 冻结评估检查四个网络eval及requires_grad=False、前后hash、学习/回放计数及采样RNG不变。通过本阶段也不会自动启动下一阶段。

原始帧只用于真实闭环感知和首末图证据，不制作视频。本实验的action-end统计不能证明动作间的连续画面质量；墙钟控制耗时另行记录。
