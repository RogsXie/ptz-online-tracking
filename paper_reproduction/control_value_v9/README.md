# 固定脉冲 Double DQN 静态可行性试验

这是明确改变算法的方向选择试验，不再称为P-DQN。目标是先学会Stay/上/下/左/右；每个动作固定0.04秒（0.32度移动），不学习连续时长，不做主动变焦。动作完全由网络或均匀随机探索选择，没有按误差方向硬编码专家动作，也没有强制居中Stay。

新控制权重和空回放，初始化20261106（不从离线对照中挑最佳权重）。离线2×2、3初始化对照已按1000更新预算完成：全部组未越界，故未复现长期高估；近中心Stay结果有明显初始化差异，不能声称Double DQN已解决问题。对照仅满足预先写明的数值放行条件。

真实试验最多60回合，沿用v8的60种组合及真实场景。epsilon全程0.4，保证第一轮完整覆盖前不降至低探索；冻结探针epsilon0。Q学习率0.0005、batch128，256转移预热，之后每4次实际转移更新1次，目标网络每100次Q更新同步；参数学习率不启用，参数目标记未更新。历史配置中的0.0001只是未使用优化器的兼容字段，不能报告为实际发生的参数训练。

同时改变估值方式、固定时长、探索与更新密度，是一个简化组合方案的可行性试验，不能将在线改善单独归因于Double DQN。一个训练初始化也不能证明跨随机种子的稳健性。

第20/40轮执行同一20例开发探针，第60轮执行完整60例。第20轮起，如果已居中案例不能全部保持，则停止复查；任一中间探针至少半数持续丢失/停滞，或平均反向超过12且无严格成功数改善，也停止。第60轮必须60/60才能启动未使用过的独立120例及全部分组门槛。失败即结束本配置，不自动追加预算或启动新配方。

训练每次决策保存原始Q和按RGB成本计算的Q上界，不裁剪Q。学习已更新256次之后，最近200次决策中超过10次的最优Q超出上界1以上，立即停止并标记review_required；探针越界比例超过1%或最大超出1以上也停止。NaN/Inf、时长/执行/hash异常按程序异常停止。

奖励、状态、相机、检测器/ReID及v8所有质量门槛不变。四个命名网络均在探针中eval且requires_grad=False，两个时长网络训练期间也永久冻结。时限truncated=True、terminated=False、实际末观测bootstrap，回放done=False。

独立验证仍要求总体114/120，每象限28/30、距离23/24、尺度38/40、每交叉组合1/2、已居中24/24。通过也只代表静态多初始尺度阶段，不代表主动变焦或运动追踪。最终测试分区仍封存。

整次真实试验另设2小时墙钟预算，每回合开始前检查；耗尽则停止复查，不自动延长。
