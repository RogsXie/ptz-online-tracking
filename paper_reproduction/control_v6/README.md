# v6：按物理时间一致计算价值目标

用户在 v5 停止并完成设计复查后明确要求“继续优化”，因此开启一个新的有界尝试。保留 v5 的失败检查点、1803 条真实交互、3096 次更新及独立验证35/40结果。本配置从新权重和空回放开始，最多32轮，不自动派生下一套配置。

## 已定位的问题与范围

v5 每次动作固定乘0.98，而动作持续0.04–0.25秒。对相同的静止图像过程，1秒后的折扣会因决策分段从0.60346变到0.92237；单位常量奖励率的无限期价值从2变到12.5。训练日志中433条近静止Stay记录覆盖完整时长范围。此时间偏置由公式和本地日志确认，但尚未证明它是此前5个验证失败的唯一原因。

此次只修复价值目标的时间语义：

- 参考时长tau=0.145秒、参考gamma=0.98。beta=-log(0.98)/tau，折扣g(dt)=exp(-beta*dt)。所有动作经过相同物理时间的折扣相同。
- 使用回放实际执行的动作参数作为dt；不使用下一步候选时长或Stay槽。窗口截断仍保留实际末观测的bootstrap。
- 保留图像奖励率：中心误差<=0.025时为1，否则为-0.2，再减6倍误差；丢失为-8。常量率积分改为rate*(1-g(dt))/beta。
- 整个动作区间的率仍近似为动作末RGB观测的率；没有读取未观测图像轨迹，也不声称积分了真实中间图像。
- 保留图像势函数Phi(s)=-20*cost(s)，引导项改为g(dt)*Phi(s')-Phi(s)，与目标折扣一致。非Stay的每次命令成本-0.02保持不变。
- 网络结构、动作Q隔离、参数梯度、时长范围0.04–0.25秒、速度8度/秒、学习率、batch和质量门槛均保持v5设置。状态仍为当前RGB几何/置信度+4零槽，无历史或倒计时，仅静态固定FOV。

这使固定状态下的长期Stay价值不再因决策切分而改变。它是数学一致性修复，不能保证函数近似器学到合格策略。

理论依据：Sutton、Precup、Singh的[时长可变动作/SMDP框架](https://www.sciencedirect.com/science/article/pii/S0004370299000521)；Ng、Harada、Russell的[势函数奖励引导](https://people.eecs.berkeley.edu/~pabbeel/cs287-fa09/readings/NgHaradaRussell-shaping-ICML1999.pdf)。本实现的连续时间折扣和端点率积分是明确记录的工程建模，不冒称作者HAS-CAM源码。

## 预先固定的实验

Qlr0.0005，参数lr0.0001，batch128，256条预热，每条真实交互2次更新，每100次更新同步target。保持相同训练/探针场景与初始化随机种子用于开发比较，不把这些场景称为独立测试。

每8轮做8例训练分区冻结探针，8/8通过才进行40例新验证。`evaluation-manifest.json`在训练开始前声明：训练211000–211031，探针219100–219107，新验证510040–510079。此前510000–510039已用于诊断，不再作为新独立验证。新块场景分布与原生成器一致，四方向各10例；逐例质量协议hash不变，仍至少38/40且每组至少9/10。最终测试保留。

出现执行/数值异常立即停止检查。探针持续坍缩/丢失/严重振荡或32轮未通过时停止；验证失败立即停止。保留现场，完成只读诊断，不自动追加同配方轮数或建立新配置。静态阶段即使通过也不代表运动目标精准追踪完成。

实现检查位于 `verification/temporal-static-v6-20261031/contract-checks.json`；时间偏置反例位于同目录 `time-consistency-evidence.json`。测试覆盖CPU/CUDA实际动作时长目标、截断、真终止、冻结状态、精确恢复、旧格式拒绝和新分区门槛。测试通过不是实际控制通过。
