# 潜势分解固定脉冲Double DQN：v10有界试验

用户在v9失败后要求解释并尝试解决。已确认的失败是近中心贪婪动作排序退化，不是检测器漏检、机械执行错误或Q上界越界。新候选保留原奖励、RGB状态和物理时间折扣，把已有奖励中的共同状态项显式分解为 `Q(s,a)=20*c_RGB(s)+U(s,a)`，网络学习U。动作仍由学习输出argmax产生，不注入专家方向、GT、居中Stay规则或新奖励。

离线两组×三个初始化、各8000更新的配对实验已完成。候选最后检查点的历史成功Stay状态一致率为100%、100%、95%，原方案64.8%、90%、60%；候选远端移动比例100%、93.43%、100%。这些是相关历史状态上的动作诊断，不是独立控制成功率。候选部分中间检查点仍退化，不能保证在线训练稳定，更不能宣称已修复。

原离线报告的float32比例将恰好2394/2520表示为0.949999988，导致95%边界误判。保留原报告，使用保存的最后检查点按整数交叉相乘复核原门槛；未追加更新、未换数据、未调整门槛。复核见gate-recheck.json。

真实UE只允许一次新权重、空回放试验，seed20261113。最多60完整训练回合，覆盖原60组合一个周期；训练及中间探针累计2小时预算按训练回合检查。训练epsilon0.4；五动作固定0.04秒、8度/秒，主动变焦关闭；Qlr0.0005，batch128，预热256，每4真实训练交互更新一次，目标网络每100更新同步。参数网络和参数优化器不更新。保留原Q上界筛查，不裁剪Q。

20/40轮同一20例开发探针，60轮完整60例。已居中开发案例一旦完成并失败，立即抛出策略复查停止；半数计划案例持续丢失/停滞、Q越界或完整探针严重反向且共同案例严格成功无改善也停止。60/60且所有复查通过才执行未用过的独立120例，原114/120及分组、已居中24/24、12秒回中、20秒窗口、5秒稳定、精度与反向门槛不变。失败不追加轮数、不自动改配方或重启。

四网络在所有探针期间eval、requires_grad=False，实际冻结回执和部分报告在finally保存。策略失败标记review_required；STOP_REQUEST的用户停止保持单独分类。时限末truncated=True、terminated=False、replay.done=False，实际末观测参与bootstrap。前端检测器、ReID、机位、天空限制、场景和最终测试封存规则均沿用已授权配置，无视频。
