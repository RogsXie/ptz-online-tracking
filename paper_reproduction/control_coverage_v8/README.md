# 固定俯视机位下的二维、多距离、多初始尺度训练

本版本接续用户“再微调一下”及对“四角”的澄清：四象限中同时包含多个距离层，层内横纵偏移随机；包含已居中和极近中心；叠加多种初始尺度。不是只有四个点，也不是只沿四条对角线。

检测器已完成一次固定 12 轮的俯视适配，新权重为 `weights/yolo26s_ue_overhead_v1.pt`。独立图像验证 128/128 目标检出、0 误检，32 空场无误检；旧视角回归 78/78 检出、1 误检。原来右下角漏检的原始 PNG 现置信度 0.9461066。44 个旧开发起点的真实 UE + ReID 复核共 220 次观测均通过。以上是感知证据，不是云台控制通过。原检测器与 ReID 文件保留；本控制试验重新冻结新检测器，阈值 0.15、输入 960、推理 FP32、ReID 不变。

## 场景分布

- 固定安装位置 `[-2200,0,4500]cm`，初始朝向 `[-60,0,0]°`，水平限位 ±65°，俯仰限位 [-80,-40]°；原生 1.0 倍车辆，黄色立柱已移除。
- 四象限 × 五个偏移层 × 三组初始 FOV，共 60 个组合。偏移按图像中心的最大轴距离分层：0.001–0.006、0.020–0.065、0.075–0.150、0.160–0.250、0.260–0.340。除已居中层外，另一轴独立随机，主轴随机，形成二维区域。
- 训练初始 FOV 为 41.25–42.75、51.25–52.75、61.25–62.75 度。独立验证使用未参与梯度训练的 45.25–46.75、55.25–56.75、65–66 度及新位置组合。对象物理尺寸不变。
- **这里是初始尺度多样化：每回合内 FOV 固定，学习动作仍为 Stay/上下/左右。主动变焦没有启用，也没有被称为已通过。**
- 种子分区：训练 2100000–2101199，开发探针 2200000–2200059，独立验证 2300000–2300119，校准 2500000–2500125。最终测试 2400000–2400239 不开放。
- 候选训练池 1200 个，按需生成；本轮仅运行第一轮均衡 60 个组合，每例一个真实在线交互回合。不是把 1200 张图片当成强化学习，也不是声称已经训练了 1200 回合。
- 校准 126 个开发起点已全部通过真实 RGB 框位置、完整可见、唯一检测和正确目标检查。检测框分布图和可筛选真实画面保存在 `verification/coverage-static-v8-20261031/scene-coverage.html`。它们不是独立控制验证。不同种子并非覆盖的唯一依据；图中展示实际二维位置和框面积，独立验证还留出不同 FOV 范围。

## 控制与验收

全新控制权重和空回放，保留 v7 的状态、动作 Q 隔离、时长梯度、连续时间奖励和时限 bootstrap 语义。检测器不再在线更新。Q 学习率 0.0005，参数学习率 0.0001，batch 128；256 条预热，每条真实交互最多两次更新，物理动作 0.04–0.25 秒、8°/s。

最多 60 轮，每 20 轮冻结四网络检查开发探针。第 20/40 轮使用相同 20 个开发案例，便于比较；第 60 轮使用全部 60 个组合，必须全过才做独立 120 例。早期子集不能宣称通过整个分布。

保留原来的每例 20 秒窗口、12 秒居中时限、5 秒持续稳定、中心均值 ≤0.025、p95 ≤0.05、可用性、身份正确性和反向限制。离线几何核对 1200 个训练候选及 126 校准条件，最大理想串行转动约 6.922 秒；FOV 最大 66° 时整个机械域的视锥仍落在地面板内。

独立验证必须至少 114/120 通过，且每象限 ≥28/30、每距离层 ≥23/24、每尺度组 ≥38/40、每个交叉组合 ≥1/2，已居中层 24/24 全过。所有 120 个案例必须执行，无重复或漏例。旧 40 例结果不能替代本验收。

运行中的数值、时长、机械执行异常立即停止并保留检查点。第 40 轮起若一半探针持续丢失/停滞，或严重反向无改善，则停止复查；60 轮未通过则结束本次尝试，不自动扩训或新开配方。探针失败、独立验证失败与程序异常分别记录。

入口：`scripts/train_coverage_control_50mamba.py --output <全新目录> --episodes 60 --headless`。运行前强制检查新协议的代码测试及 126 例初始校准结果。
