# 固定俯视机位、四角到中心：独立 v7 尝试

用户再次授权“继续优化”，并要求四角起点、移除黄色立柱，以及“固定机位，云台仍可转动，镜头对着地面板，不拍天空”。旧 v3/v4/v5 的失败日志、权重与回放保留。本轮使用新权重和空回放，最多32轮；不自动启动下一套配置。

## 场景与相机约定

所有新场景使用同一安装位置 `[-2200,0,4500] cm`，初始姿态 `[-60,0,0] deg`，无机位/姿态随机抖动。云台水平范围为±65°，俯仰范围为向下40°–80°，FOV固定60°，速度8°/s。运行时核对位置不变、角度响应及边界。整个视锥在此范围内朝下，并落在原有地面板内；数学边界和9个真实极限/中间姿态截图另行留证。未删除天空来伪造朝向。

黄色参考立柱的18个运行时实例和6个编辑器预览实例已从 `PTZArena.cpp` 移除，并编译新UE模块。原源码/DLL及原始含立柱图片备份在 `verification/four-corners-v7-20261031/scene-before-user-cleanup`。这是用户授权的环境变更；旧试验的历史模块hash不与新模块混用。

车辆位置按固定相机的预先设计投影放置在地面板上；这仅用于场景生成，不读取实时GT进行重置瞄准、策略控制或奖励计算。每例真实RGB必须确认角落区域及完整包围框。四角中心区为横纵 `.06–.20` 或 `.80–.94`，包围框离边缘至少 `.005`。原1.8倍车辆在俯视近端会出框，校准r2如实保留；新场景统一使用原生1.0倍、约4米车身，校准r3四角完整可见。检测器、ReID及阈值/输入均未修改。

## 学习修复及边界

使用已验证v6时间语义：实际执行时长dt对应折扣 `exp(log(.98)*dt/.145)`；RGB势函数引导与该折扣一致，奖励率使用动作末图像的分段常量积分。公式与时长偏置证据见 `../control_v6/README.md`。这不是作者原公式，也未证明能解决全部策略失败。

静态观测为完整图像归一化x/y的4倍、尺度、置信度和4个零槽；取消旧观测对半幅以外坐标的裁剪。无历史动作、倒计时、GT或专家控制。动作Q隔离、学习率和参数梯度继承v3；Qlr=0.0005，参数lr=0.0001，batch128，256条预热，每条真实交互2次更新。时长0.04–0.25秒。20秒采样结束是truncated，不是真正terminated；回放保留真实末观测bootstrap，不能混入下一次reset图像。

## 预先确定的训练与验收

- 训练711000–711031：12例循环覆盖4角、4边、4近中心；最多32轮。
- 每8轮冻结四个网络，执行719100–719111共12例训练分区探针，需12/12才能启动验证。探针不是独立验证。
- 独立验证810000–810039，共40例新四角场景，每角10例；至少38/40且每角至少9/10。最终测试分区保留。
- 固定机位的新角落布局需最多约7.20秒理想串行转动；在训练前设置12秒居中时限、20秒窗口、最多512动作。原0.025平均中心误差、0.05尾部误差、5秒持续稳定、目标正确性、可用率及反向限制不降低。动作末RGB采样不能证明采样之间的连续像素轨迹。
- 记录每轮损失、参数最大化目标、奖励、epsilon、步数和更新数。保留每例真实起点、4秒中间帧和最终帧；最终帧只有质量检查通过才称稳定。
- 数值/执行异常立即停止；持续贪婪策略坍缩、丢失、严重振荡或预算结束时停下复查，不只增加轮数。静态阶段通过也不代表运动跟踪完成。
