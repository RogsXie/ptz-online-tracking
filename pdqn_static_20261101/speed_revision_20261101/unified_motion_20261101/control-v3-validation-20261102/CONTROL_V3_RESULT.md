# PTZ 控制 v3（2026-11-02）

已选为本地默认摄像机控制版本。检测器、ReID 权重、原始跟踪算法保持不变，旧版权重保留，未修改私人仓库发布版本。

## 这次修正

- 放大前根据真实 RGB 运动和本机反馈时间预测下一次观测的位置，保留居中余量，避免连续放大挤掉快速目标。
- 接近画面边缘时优先处理可能越界的轴，避免目标接近上沿却先横转。
- 短时无框时，用最后真实 RGB 观测的角度/速度指导相机搜寻，每次脉冲最多6度，同时逐步放宽到66度。沿用3秒遗忘时间，不补画预测框，也不改变目标选择/关联。
- 在本轮从头训练的模型上新增8个急弯布局、768条真实交互、384次原作者 P-DQN 联合更新。四个网络均有真实更新；累计11,008条交互、4,992次源算法更新。未使用此前已拒绝的时长拟合权重。

控制改进包含执行规则和继续训练，不能把全部效果归因于网络权重。所有场景坐标、路线和物体真值仅用于生成布局或运行后的独立评分，不进入控制与训练奖励。
